# Frictional contact paper experiments

The maintained entry point is [`paper_current/run.py`](paper_current/run.py).
See [`paper_current/README.md`](paper_current/README.md) for current manuscript
figure mappings, archived plotting inputs, new simulation commands, training
configurations, and optional raw-data requirements.

Modify `paper_current/scripts/` first when changing paper figures. The older
top-level experiment scripts remain historical standalone entry points;
they are not an independently maintained plotting pipeline.
